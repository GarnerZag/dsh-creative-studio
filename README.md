## 当前实现

- 原生左侧入口、项目创建/切换、Host 持久化、中文/英文界面。
- 可选择编辑的 SVG 需求树，层级、优先级、桌面/手机验收条件；独立指针拖柄调整父子关系，同级排序，需求依赖（先决条件，独立于父子层级，拒绝悬空/重复/成环并点名相关节点），当前页面内最近 20 次已保存需求编辑的撤销／重做。
- 架构模块、契约、决策、任务及依赖编辑；版本差异、用户审批、任务计划确认。
- 独立需求推导会话，候选与草稿分离；候选 Demo 可预览，采纳不等于审批。
- 手动参考来源及未核验的模型推荐、功能对比矩阵；研究会话的只读来源约束、实际工具结果记录和带限制的总结。推荐逐条确认加入参考库，研究单独启动，摘要可经确认预填推导输入，再由用户决定是否生成候选。
- 受约束的声明式 Demo：状态、输入、列表过滤、按钮、播放/暂停/重置；桌面与手机真实 CSS 视口，沙箱与禁网 CSP。
- 已批准版本生成便携 ZIP（需求、架构、任务、验收、离线 Demo、清单）；开发会话派发和按任务回传报告，用户验收单独确认。

## 构建与测试

当前 SDK 基线：Node.js 24、DeepSeek Harness **0.2.2-rc.1**、Cordis 4.1.x。其他版本未经验证，不建议绕过版本要求。

```sh
npm ci --include=dev --ignore-scripts
npm run build
npm run typecheck
npm run test:unit
```

浏览器测试需要 Playwright Chromium 及系统依赖；`test/demo-browser.mjs` 是隔离的测试夹具，不是替代 Harness 的独立产品服务。

`build` 用官方 Typert generator 生成 Host/Client 契约，再将客户端打包为原生惰性模块工厂。临时编译工作区仅用于识别已发布协议声明，不修改 Harness 核心或手写 Remote 描述符。

## 安装开发预览版

1. 在独立源码目录安装依赖并构建。
2. 通过 Harness 官方插件管理器安装本目录的绝对路径，不手工修改 profile。
3. 若更新提示已安装，按管理器提示移除本插件后重装；不要删除项目数据或卸载其他插件。
4. Remote 接口变化后重启原 Harness，并重新打开页面。确认侧栏、Host 连接及实际项目操作，不只检查安装成功提示。

正式分发应包含构建后的 Host/Client、生成契约、语言资源及图标；仅下载源代码 ZIP 不等于已得到可直接安装的构建包。

## 使用与权限边界

AI 提供候选，用户决定采纳/审批。研究启动会显示参考内容可能发送给所配置模型及费用提示；请仅使用有权研究的材料。模型结论是推断，工具输出的覆盖不足/失败/未知不能抹去。
